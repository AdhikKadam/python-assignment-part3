# Assignment — Part 3: File I/O, APIs & Exception Handling

## Overview
This repository contains a Python-based project demonstrating fundamental Data Engineering skills, including:
- **File I/O**: Reading, writing, and appending to text files.
- **API Integration**: Making GET and POST requests to the DummyJSON public API.
- **Data Processing**: Parsing JSON, filtering, and sorting data.
- **Exception Handling**: Building resilient functions that handle division errors, missing files, and network timeouts.
- **Error Logging**: Implementing a custom logger that records timestamped errors to a text file.

## Files
- `part3_api_files.ipynb`: The main Jupyter Notebook containing all the code.
- `python_notes.txt`: A text file generated by the script demonstrating File I/O.
- `error_log.txt`: A log file generated by the script capturing simulated network and HTTP errors.

## How to Run
1. Clone the repository.
2. Ensure you have the `requests` library installed (`pip install requests`).
3. Open `part3_api_files.ipynb` in Jupyter Notebook or VS Code and run the cells sequentially.
